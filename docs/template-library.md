# 模板资产库

## 定位

模板资产库是第一个顶级栏目，内部包含两个平级部分：

- “模板分类”负责浏览、筛选、复制和选择模板。
- “素材库”按视频、图片、音频保存并预览 TOS 素材。
- Seedance 负责视频连接配置、请求审核、真实创建、轮询、历史和日志。
- 模板本身不会自动创建任务；只有进入实操台、完成费用确认并点击执行后才会调用真实 API。

## 素材库

- Seedance 当前结果与历史成功视频可显式保存；Seedream 每张结果可单独保存，多图可批量保存。
- 视频、图片、音频均支持本地文件手动上传。默认上限依次为 200 MB、20 MB、50 MB，MIME 必须匹配所选栏目。
- 文件写入私有 TOS 的 `demo/{video|image|audio}/`；D1 保存长期元数据索引，预览通过同源接口按需获取 1 小时签名地址，媒体失败时重新签名。
- 图片在服务端完成 MIME 与大小校验后以固定长度二进制请求体上传，兼容 Worker 到 TOS 的 PUT；视频和音频仍使用限流流式上传。
- 页面加载会使用服务端 Header 签名分页列举三个固定 TOS 前缀，解析 TOS 原生 JSON（并兼容 XML）后与 D1 对账、补建旧对象。目录结果缺少已索引对象时必须再做 HEAD 校验，只有对象确认为 404 才删除索引。手动上传从对象键恢复原文件名；旧生成素材无法恢复原名称时显示“类型 + 日期”回退名称。
- 当前浏览器最多缓存 500 条 `MaterialAsset`，不保存原始结果 URL、文件内容、预签名 URL 或凭证。已有浏览器缓存会先通过 TOS HEAD 校验对象仍存在，再补写 D1，避免升级持久索引时丢失旧卡片。
- 若当前凭证缺少 `tos:ListBucket`，目录扫描会降级为 D1 与本机缓存，单对象预览仍可使用；此时已索引素材可跨浏览器恢复，但从未进入 D1 的历史对象只有补齐列举权限后才能自动发现。
- 素材卡片采用紧凑图片墙，名称与操作叠加在预览图上；修改名称持久化到 D1，不移动 TOS 对象。“复制 URL”获取当前有效的 1 小时 TOS 预签名 URL，不是永久公开链接。
- 删除需要在卡片内二次确认；服务端从 D1 获取受控对象键，先删除 TOS 对象，再删除 D1 索引。若桶启用多版本，普通删除可能创建 DeleteMarker，不清理全部历史版本。
- 当前本地入口无应用内身份鉴权；列举需要 `tos:ListBucket`，删除需要 `tos:DeleteObject`。恢复公开部署前必须重新评估素材隔离和删除授权。

## Seedance 2.5 能力示例模板

新增 20 条模板，覆盖文档全部 10 个能力示例：

- 提示词模板 10 条：完整保留文档原文提示词，tags 标注能力类型（白模渲染/分镜参考/关键帧/指令编辑/音频编辑/延长/一键成片/转场）。
- 可运行模板 10 条：影视短剧 7 条（粗粒度白模、细粒度白模、多宫格分镜、视频指令编辑、参考图编辑、音频编辑、视频延长）、营销短视频 3 条（像素武侠关键帧、一键成片、无缝转场）。
- 模型统一使用 `doubao-seedance-2-0-mini-260615`；文档原示例为 Seedance 2.5 · 30 秒的，duration 封顶 15 秒，`modelNote` 注明适配说明。
- 输入素材通过 `materialSlots` 声明：每个槽位记录 requestBody `content` 下标、私有 TOS objectKey 与素材类型。模板中的媒体 URL 留空占位。

### 素材托管与填入流程

- 模板数据只保存 TOS objectKey，不保存任何签名 URL。
- “填入实操台”时，`applyTemplate` 先对每个 objectKey 调用 `materialTosUrl()` 获取 1 小时预签名 URL，再按 `contentIndex` 填入深拷贝后的 requestBody，随后派发 `seedance:apply-example` 事件并跳转实操台。
- 任一槽位换取或匹配失败时展示错误提示且不跳转，不产生半预填状态。
- 预览图使用 `/api/materials/object?key=...` 302 代理相对路径，同样不落盘签名 URL。

## 两个可运行电商案例

两个案例均使用标准官方 API 的 `doubao-seedance-2-0-mini-260615`：

1. 云朵面霜：1 张公开商品图、9:16、8 秒、有声、有水印。
2. 冰爽果茶：1 张公开果茶商品图、9:16、8 秒、有声、有水印。

点击“填入实操台”会发出与官方示例相同的 `seedance:apply-example`
事件，因此模型、提示词、素材、比例、时长、音频和水印与完整 Request Body
共用同一份状态。任务提交后继续写入现有浏览器历史和脱敏日志。

## 影视与营销模板预填

8 个影视和营销模板都提供“填入实操台”：

- 可直接运行：剧情向后延长、骏马变黄金吊坠、科技园区概念片。请求已带入官方公开素材。
- 素材待补：武侠双人对决、影视打斗动作参考、父女对话分镜、品牌 Slogan 收尾、赛博都市 Logo 露出。请求保留对应数量和类型的空素材位。
- 所有模板均优先使用 `doubao-seedance-2-0-mini-260615`，并预置提示词、比例、时长、音频与水印参数。
- 预填只改变页面状态并跳转到 `#operations`，不读取或提交 Key，也不会创建计费任务。

## 维护规则

- 官方模板新增或修改时，先核对官方页面更新时间，再更新本文件和模板数据。
- `source` 必须区分“火山方舟提示词指南”、“工作台预置案例”和“Seedance 2.5 使用指南”。
- `materialSlots` 的 `contentIndex` 必须与 requestBody `content` 数组中媒体项下标保持一致；素材文件重传后需同步更新 objectKey。
- 模板可以用空 URL 保留缺失素材位，但必须显示“素材待补”，且实操台在补齐前必须保持执行按钮禁用。
- 模板页加载、分类切换、复制和填入都不得自动提交任务。
- 不在模板数据、截图、文档或日志中保存 API Key、TOS AK/SK、私有结果 URL、预签名 URL 或用户素材。
