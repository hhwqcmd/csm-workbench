# 模板资产库

## 定位

模板资产库与演示工作台是两个平级顶层栏目：

- 模板资产库负责浏览、筛选、复制和选择模板。
- 演示工作台负责连接配置、请求审核、真实创建、轮询、历史和日志。
- 模板本身不会自动创建任务；只有进入实操台、完成费用确认并点击执行后才会调用真实 API。

## 四类模板

| 分类 | 内容 | 交互 |
|---|---|---|
| 提示词模板 | 官方基础公式、进阶公式、分镜与稳定性约束 | 复制提示词 |
| 电商宣发视频模板 | 云朵面霜、冰爽果茶两个工作台预置案例 | 复制提示词 / 填入实操台 |
| 影视短剧模板 | 武侠对决、打斗动作、父女对话、剧情延长 | 复制提示词 / 填入实操台 |
| 营销短视频模板 | 品牌 Slogan、黄金吊坠、科技园区、赛博 Logo | 复制提示词 / 填入实操台 |

模板数据集中在 `app/lib/template-assets.ts`，展示和分类交互位于
`app/components/TemplateAssetLibrary.tsx`。

## 官方来源

官方公式和案例移植自：

- [Doubao Seedance 2.0 系列提示词指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)
- 读取时页面最近更新时间：2026-07-20 15:12:21

官方内容保持原有素材序号和指代方式。官方公开素材会随请求一起带入；缺少独立素材的案例以空 URL 素材位表示，并显示“素材待补”。由于实操台要求所有素材 URL 非空，这类请求在补齐前无法执行。

## 两个可运行电商案例

两个案例均使用标准官方 API 的 `doubao-seedance-2-0-mini-260615`：

1. 云朵面霜：1 张公开商品图、9:16、8 秒、有声、有水印。
2. 冰爽果茶：1 张公开果茶商品图、9:16、8 秒、有声、有水印。

点击“填入实操台”会发出与官方示例相同的 `seedance:apply-example`
事件，因此模型、提示词、素材、比例、时长、音频和水印与完整 Request Body
共用同一份状态。任务提交后继续写入现有浏览器历史和脱敏日志。

## 影视与营销模板预填

8 个影视和营销模板都提供“填入实操台”：

- 可直接运行：剧情向后延长、骏马变黄金吊坠、科技园区概念片。请求已带入官方公开素材。
- 素材待补：武侠双人对决、影视打斗动作参考、父女对话分镜、品牌 Slogan 收尾、赛博都市 Logo 露出。请求保留对应数量和类型的空素材位。
- 所有模板均优先使用 `doubao-seedance-2-0-mini-260615`，并预置提示词、比例、时长、音频与水印参数。
- 预填只改变页面状态并跳转到 `#operations`，不读取或提交 Key，也不会创建计费任务。

## 维护规则

- 官方模板新增或修改时，先核对官方页面更新时间，再更新本文件和模板数据。
- `source` 必须区分“火山方舟提示词指南”和“工作台预置案例”。
- 模板可以用空 URL 保留缺失素材位，但必须显示“素材待补”，且实操台在补齐前必须保持执行按钮禁用。
- 模板页加载、分类切换、复制和填入都不得自动提交任务。
- 不在模板数据、截图、文档或日志中保存 API Key、私有结果 URL 或用户素材。

## 真实验证

2026-07-28 使用标准官方 API 与 `doubao-seedance-2-0-mini-260615`
验证两个电商模板：

- 云朵面霜：请求创建成功并达到 `succeeded`。
- 最初选用的官方随行杯拼图宽高比为 2.87，被上游以图片允许范围
  0.40–2.50 拒绝；失败请求和响应保留在历史日志中。
- 将第二个案例改为已验证可访问的果茶商品图后，请求创建成功并达到
  `succeeded`。
- 刷新页面后，两条成功任务、一次输入失败及此前历史均恢复；最新日志同时包含
  创建和状态查询，Authorization 只保留掩码。

同日新增影视与营销预填入口后：

- 影视“剧情向后延长”使用官方公开参考视频创建真实任务，创建、轮询与终态均写入同一历史和脱敏日志。
- 营销“骏马变黄金吊坠”使用官方公开参考视频创建真实任务，创建、轮询与终态均写入同一历史和脱敏日志。
- 对“素材待补”模板验证了空素材位会阻止执行，补齐后才可进入费用确认与提交。
