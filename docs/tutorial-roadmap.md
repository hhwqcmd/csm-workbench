## Step 3：跑通官方任务（已完成）

已实现：

- 工作台提供 API 路径、Base URL、模型与 API Key 输入。
- 工作台提供提示词、参考图片/视频、时长、比例、音频和水印参数。
- 同源服务端校验路径与模型后创建任务，不在浏览器直连火山方舟。
- 创建成功后每 30 秒查询 `queued/running/succeeded/failed` 状态并展示结果。
- 活跃任务和最近 30 条历史保存在当前浏览器；刷新后可恢复并继续轮询。
- 演示模式可按 API 路径记住 Key，便于刷新后续查；Key 仍不进入 URL、源码或服务端持久化。
- 执行按钮只有在参数有效并完成费用确认后才启用。
- 构建和测试使用模拟上游响应，不会自动创建真实任务。

真实验收（2026-07-24）：

- 使用官方 API、`doubao-seedance-2-0-260128`、官方图片与视频素材创建任务。
- 任务 `cgt-20260724165550-rwll7` 从排队进入运行，持续多轮 30 秒查询后成功返回结果 URL。
- 创建后与成功后分别刷新页面，历史、任务状态和结果入口均成功恢复。
- 结果 URL 只保存在当前浏览器历史中，不写入项目文档或提交记录。

验收条件已满足：取得成功结果 URL。

注意：真实调用会消耗额度或产生费用。标准 API 按标准规则计费；只有使用
`/api/plan/v3` 与 Agent Plan 专属 Key 时才消耗套餐 AFP。

计划：

- 服务端只在单次请求期间使用 API Key；演示模式可由浏览器按路径记住 Key。
- UI 展示提示词、素材、参数、任务 ID、状态时间线和结果。

- 真实调用前显示成本/参数摘要并要求明确操作。

验收条件：Key 不进入 URL、源码、服务端持久化或日志，真实路径通过服务端完成；受控设备可明确选择浏览器本地记住。
